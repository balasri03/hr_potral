# MHK People Portal — Professional Neutral Edition

A responsive HR portal frontend built with React, Vite, JavaScript, React Router, Lucide icons and Recharts.

## Visual direction
- Apple-inspired minimalism: white surfaces, soft neutral-grey backgrounds, charcoal typography and generous spacing.
- Warm champagne accents for primary highlights; no blue or teal accents.
- Restrained green, amber and red are used only for meaningful status states.

## Demo features
- Admin, HR and Employee role switching
- Dashboard metrics and charts
- Employee directory and CSV export
- Demo leave requests and approval/rejection actions
- Responsive layouts and sample data

## Run locally
Requires Node.js (LTS) and npm.

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```

This is a frontend prototype with mock data; it does not connect to a live HR database or provide production authentication/authorization.
